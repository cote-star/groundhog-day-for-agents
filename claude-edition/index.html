The receipts · symptoms (h/t Mario Zechner)

Things the harness does behind your back

The system prompt changes every release. Tools added, removed, renamed. Your agent's personality is on a rolling update.
System reminders injected "in the most opportune place" — literally tells the model: "this may or may not be relevant."
LSP runs after every edit. Imagine compiling after every line you type.
Zero observability by default. You don't see what the harness mutates.
Compounding boooos — small errors stack across turns. No bottleneck. Pain delayed.
Locally patches. Globally fuxes. The diff works. The system doesn't.

The harder questions — and the case file so far

Where do the tattoos live?

settled-ish

Where should shared memory live?

In the repo, in git. Treat memory like code: diffed, reviewed, shipped with the project. That's why everything converged on files — every clone is a brain transplant, on purpose.

emerging

Personal vs team — who sees what you taught it?

Two layers are forming: private memory dirs for what one agent learned, repo packs for team truth. Keep them separate — mixing them is how preferences leak into shared maps.

open

Code changes — who invalidates stale memory?

Freshness gates in CI can flag drift. Mostly, though: still nobody. Why it matters: a stale map routes the agent wrong faster than no map at all.

wide open

What if prompt injection writes to memory?

Today's only defense: review memory diffs before they land. Why this one matters most: poisoned context dies with the session — poisoned memory survives into every future one.

Harness engineering is becoming a real discipline. Not just vibes.

→ walkinglabs.github.io/learn-harness-engineering · arXiv:2605.18747

where we end up
Your agent's biography has just begun.

We keep mistaking context for continuity.

Should memory be opt-in, opt-out, or default-on? my bet: default-on for project facts, opt-in for personal — and every write lands as a visible diff.
Is forgetting sometimes a feature? yes. a clean slate is how you escape poisoned context. ephemeral runs deserve first-class support.
Multi-agent: who owns the shared tattoos? the repo. shared memory is code — owners, review, history. no orphan brains.
